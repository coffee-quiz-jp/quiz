# Black Apron 対策 — パスコード保護版（v25）

BlackApronQuiz（DATA_VERSION 22 / 198問＋電車版カード575枚）のPWAです。
このバージョンから、問題データと画像は **AES-256-GCMで暗号化** されて配信されます。
URLを知られても、合言葉を知らない人には中身（問題文・画像・ソース）は一切見えません。

## 中身（公開フォルダに置くもの）

| ファイル | 役割 |
|---|---|
| `index.html` | 起動ページ。初回に合言葉を確認 → 復号 → JSX変換。以後は端末内キャッシュで即起動 |
| `app.enc` | アプリ本体（app.jsx）の暗号化データ |
| `assets.enc` | 画像54点（assets.js）の暗号化データ |
| `manifest.webmanifest` / `sw.js` / `icon-*.png` | PWA設定・オフライン対応・アイコン |

**`app.jsx` / `assets.js`（平文）と `encrypt-tool.html` / `encrypt.mjs` は絶対に公開フォルダに置かないでください。**

## 合言葉のしくみ

- 初回起動時に合言葉を入力。正しければ復号され、端末内に鍵が保存されるので**2回目以降は入力不要**（オフラインでも起動可）。
- 合言葉そのものはどこにも保存・送信されません（PBKDF2-SHA256 31万回で鍵を導出）。
- Safariの「履歴とWebサイトデータを消去」をすると、鍵も消えるため再入力が必要になります（学習進捗も消えます）。

## 配布のしかた

1. GitHub Pages / Cloudflare Pages 等にこのフォルダの中身をアップロード（HTTPS必須）
2. 従業員にはURLと合言葉を**別々の経路**で伝える（例：URLはメッセージ、合言葉は口頭）
3. Safariで開く → 合言葉入力 → 共有ボタン → ホーム画面に追加

## 内容を更新するとき

1. 手元の `app.jsx`（または `assets.js`）を編集（`DATA_VERSION` を +1）
2. `encrypt-tool.html` をブラウザで開いてファイルと合言葉を指定し、`app.enc` / `assets.enc` を再生成
   （Nodeがあれば `node encrypt.mjs "合言葉"` でも可）
3. `index.html` の `BUILD` と `sw.js` の `CACHE` の数字を +1
4. `.enc` と `index.html` / `sw.js` を上書きアップロード

合言葉を変更した場合は、全員の端末で次回オンライン起動時に再入力が求められます。

## セキュリティの範囲（正直な注意書き）

**守れるもの**：URLの偶然の発見・検索エンジン・クローラー・合言葉を知らない外部者によるアクセス。ホスティング上に平文は存在しません。

**守れないもの**：合言葉を知っている人による転送・共有、解錠済み端末を直接触られること、極端に弱い合言葉の総当たり。社外秘資料の配布可否そのものは職場のルールに従ってください。より強固にしたい場合は、Cloudflare Access（メールアドレス認証）を入口に重ねる構成に移行できます。

## 注意点（従来どおり）

- 進捗（正誤・要注意タグ・カードの覚えた／まだ）は端末内保存。端末間で共有されません。
- 初回起動はオンライン必須。以後は機内モードでも起動します。
